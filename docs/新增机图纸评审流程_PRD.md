# 新增机图纸评审流程 — 产品需求文档（PRD）

> 版本：v1.0  
> 日期：2026-10-13  
> 状态：初稿  
> 适用范围：机械设计 / 电气控制 / 采购 / 生产 / 仓储 / 项目管理

---

## 1. 背景与目标

### 1.1 背景
当前新增机型的图纸评审依赖线下邮件、微信群、个人日历和 Excel 手工汇总，存在以下问题：
- 评审会议需人工预约，容易遗漏关键成员；
- 会议纪要、评审结论散落，难以追溯；
- BOM、电控评估、布线评估与后续采购、生产、发货脱节；
- 库存数据、MES 位置、加工件 BOM、询价单等需跨系统手工搬运；
- 流程节点不透明，项目排期依赖口头沟通。

### 1.2 目标
建设「新增机图纸评审流程」数字化工作流，实现：
1. 图纸报告书在线提交与版本管理；
2. 腾讯会议自动预约并自动勾选相关成员；
3. 会议纪要、评审结论结构化保存并关联图纸版本；
4. 评审通过后自动触发 BOM 工程量清单、电控评估、布线评估；
5. 拉取库存与 MES 位置，自动生成发货清单；
6. 基于成员时间清单自动排期；
7. 同步机械加工件 BOM 并生成三家询价单；
8. 提供流程管理看板，实时查看流程状态与阻塞点。

---

## 2. 业务流程总览

```
[提交图纸报告书]
        ↓
[系统校验图纸完整性]
        ↓
[自动创建腾讯会议并邀请成员]
        ↓
[召开评审会]
        ↓
[保存会议纪要 & 评审结论]
        ↓
      不通过 ←———→ 通过
        ↓                ↓
   [退回修改]      [生成/更新 BOM]
        ↓                ↓
   [重新提交]      [电控评估]
                        ↓
                   [布线评估]
                        ↓
                   [拉取库存 & MES 位置]
                        ↓
                   [生成发货清单]
                        ↓
                   [成员时间清单排期]
                        ↓
                   [机械加工件 BOM 同步]
                        ↓
                   [三家询价单生成]
                        ↓
                   [流程归档 & 看板更新]
```

## 3. 功能模块详细设计

### 3.1 图纸报告书提交

#### 3.1.1 输入内容
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 项目编号 | 文本 | 是 | 关联项目主数据 |
| 机型名称 | 文本 | 是 | 新增机名称 |
| 图纸版本 | 文本 | 是 | 如 V1.0、V1.1 |
| 设计负责人 | 人员 | 是 | 机械设计负责人 |
| 图纸文件 | 附件 | 是 | 支持 DWG/PDF/STEP/ZIP |
| 设计说明 | 富文本 | 是 | 关键设计参数、变更点 |
| 关联标准件清单 | 表格 | 否 | 预填的标准件参考 |
| 预计加工周期 | 数字 | 否 | 天 |
| 预计装配周期 | 数字 | 否 | 天 |

#### 3.1.2 业务规则
- 同一项目同一机型，图纸版本需递增；
- 图纸提交后自动锁定，如需修改需走「变更申请」；
- 提交成功后向设计负责人、项目经理发送通知。

#### 3.1.3 输出
- 生成「图纸评审单」唯一编号（如 DR-20261013-001）；
- 状态更新为「待评审」。

---

### 3.2 腾讯会议自动预约

#### 3.2.1 触发条件
图纸报告书提交并通过完整性校验后，系统自动预约评审会议。

#### 3.2.2 会议参数
| 参数 | 来源/默认值 |
|------|------------|
| 会议主题 | 「新增机图纸评审」-{机型名称}-{图纸版本} |
| 会议时间 | 提交后 T+1 工作日的默认时段（可配置） |
| 会议时长 | 默认 60 分钟，可根据图纸复杂度动态调整 |
| 参会成员 | 系统自动勾选，见 3.2.3 |
| 会议描述 | 自动带入图纸版本、设计说明摘要、评审单链接 |

#### 3.2.3 自动勾选成员规则
| 角色 | 是否默认勾选 | 说明 |
|------|-------------|------|
| 设计负责人 | 是 | 提交人 |
| 机械评审专家 | 是 | 按机型匹配专家库 |
| 电气/电控负责人 | 是 | 需参与电控评估 |
| 布线工艺工程师 | 是 | 需参与布线评估 |
| 采购代表 | 是 | 需评估采购可行性 |
| 生产/装配负责人 | 是 | 需评估加工与装配周期 |
| 项目经理 | 是 | 流程Owner |
| 质量工程师 | 条件勾选 | 涉及关键质量特性时 |
| 仓储/物流 | 条件勾选 | 涉及库存与发货时 |

#### 3.2.4 集成方式
- 调用腾讯会议 OpenAPI：创建会议、添加参会人、设置会议提醒；
- 在系统中保存会议 ID、会议链接、参会人列表；
- 会议开始前 15 分钟向未确认成员发送提醒。

---

### 3.3 会议纪要及评审结论保存

#### 3.3.1 会议纪要模板
| 模块 | 内容 |
|------|------|
| 基本信息 | 评审单号、机型、图纸版本、会议时间、参会人 |
| 议题 | 按预设议题清单勾选 |
| 讨论记录 | 富文本，支持图片/附件 |
| 问题清单 | 问题描述、责任人、截止日期、严重等级 |
| 评审结论 | 通过 / 有条件通过 / 不通过 |
| 下一步动作 | 动作、负责人、截止时间 |

#### 3.3.2 评审结论类型
- **通过**：进入下一流程节点（BOM 生成）。
- **有条件通过**：需记录整改项，整改完成后自动流转。
- **不通过**：退回设计负责人修改，重新触发评审。

#### 3.3.3 自动关联
- 会议纪要自动关联腾讯会议录制（如有）；
- 评审结论与图纸版本绑定，支持历史版本追溯。

---

### 3.4 BOM 工程量清单

#### 3.4.1 触发条件
评审结论为「通过」或「有条件通过且整改完成」后自动触发。

#### 3.4.2 BOM 结构
| 层级 | 说明 |
|------|------|
| L1 | 整机 |
| L2 | 大部件/子系统 |
| L3 | 零件/组件 |
| L4 | 标准件/外购件 |

#### 3.4.3 BOM 字段
| 字段 | 说明 |
|------|------|
| 物料编码 | 关联 ERP/MES 物料主数据 |
| 物料名称 | 中文名称 |
| 规格型号 | 规格参数 |
| 数量 | 单机用量 |
| 单位 | 件/套/米/公斤 |
| 材质 | 机械件必填 |
| 加工工艺 | 机加/钣金/焊接/注塑等 |
| 来源 | 自制/外购/标准件 |
| 参考图号 | 关联图纸 |
| 备注 | 特殊要求 |

#### 3.4.4 输出
- 生成「BOM 工程量清单」Excel/PDF；
- 推送至采购、生产、仓储模块。

### 3.5 电控评估

#### 3.5.1 评估内容
| 评估项 | 说明 |
|--------|------|
| 电气原理图评审 | 电压、电流、功率、保护等级 |
| PLC/控制器选型 | 与机械动作匹配 |
| 传感器/执行器清单 | 数量、型号、安装位置 |
| 安全回路评估 | 急停、门锁、光栅等 |
| 能耗评估 | 整机功率估算 |
| 电气柜布局 | 空间、散热、接线便利性 |

#### 3.5.2 输出
- 「电控评估报告」；
- 评估通过则进入布线评估；
- 不通过则返回电气负责人修改。

---

### 3.6 布线评估

#### 3.6.1 评估内容
| 评估项 | 说明 |
|--------|------|
| 线缆类型与长度 | 动力线、信号线、通讯线 |
| 走线路径 | 线槽、拖链、防护等级 |
| 接线端子与接头 | 型号、数量 |
| 线束BOM | 汇总线缆及附件 |
| 布线工时 | 预估装配工时 |

#### 3.6.2 输出
- 「布线评估报告」及「线束 BOM」；
- 合并入总 BOM。

---

### 3.7 库存数据与 MES 位置拉取

#### 3.7.1 数据来源
- **库存数据**：ERP/WMS 库存查询接口；
- **MES 位置**：MES 系统中物料的库位、工位、在制状态。

#### 3.7.2 拉取规则
- 按 BOM 物料编码批量查询库存；
- 区分自有库存、在途库存、在制库存、缺料；
- 标注物料所在仓库/库位/MES 工位。

#### 3.7.3 输出
| 状态 | 说明 |
|------|------|
| 库存充足 | 可直接出库 |
| 库存不足 | 需采购/生产 |
| 无库存 | 需新采购或新加工 |
| 在制 | 需跟踪完工日期 |

---

### 3.8 发货清单生成

#### 3.8.1 生成逻辑
基于 BOM + 库存/MES 数据，生成发货清单：
- 齐套物料按发货包装规则分组；
- 缺料物料单独列示并标注预计到货时间；
- 大件/易损件标注包装与运输要求。

#### 3.8.2 发货清单字段
| 字段 | 说明 |
|------|------|
| 发货批次 | 系统自动编号 |
| 物料编码 | 关联 BOM |
| 物料名称 | 中文名称 |
| 数量 | 发货数量 |
| 来源库位 | WMS/MES 库位 |
| 包装方式 | 箱/托/裸装 |
| 运输方式 | 物流/专车/快递 |
| 预计发货日期 | 基于排期计算 |
| 备注 | 特殊要求 |

---

### 3.9 成员时间清单与排期

#### 3.9.1 时间清单来源
- 同步企业日历/飞书/腾讯会议成员日程；
- 读取成员任务负载（可选接入项目管理系统）。

#### 3.9.2 排期逻辑
1. 获取各节点负责人可用时段；
2. 结合加工周期、采购周期、装配周期；
3. 自动生成关键路径与里程碑日期；
4. 对冲突时段高亮提示，支持人工调整。

#### 3.9.3 输出
- 「项目排期表」甘特图；
- 各节点责任人时间清单；
- 关键路径预警。

---

### 3.10 机械加工件 BOM 同步

#### 3.10.1 加工件识别
从总 BOM 中筛选来源为「自制」且工艺为「机加/钣金/焊接」的物料。

#### 3.10.2 同步内容
| 字段 | 说明 |
|------|------|
| 加工件编码 | 内部编码 |
| 零件名称 | 中文名称 |
| 材质 | 材料牌号 |
| 数量 | 需求数量 |
| 工艺路线 | 下料→机加→热处理→表面处理 |
| 加工周期 | 天数 |
| 所需设备 | 车床/铣床/CNC/激光切割等 |
| 外协标识 | 是否需外协加工 |

#### 3.10.3 输出
- 「机械加工件 BOM」推送至 MES/生产排程系统；
- 生成加工任务单草稿。

---

### 3.11 采购三家询价单

#### 3.11.1 触发条件
BOM 中来源为「外购/标准件」且库存不足的物料。

#### 3.11.2 询价单内容
| 字段 | 说明 |
|------|------|
| 询价单号 | 系统自动生成 |
| 物料编码 | 关联 BOM |
| 物料名称 | 中文名称 |
| 规格型号 | 技术参数 |
| 需求数量 | 采购数量 |
| 需求日期 | 基于排期 |
| 推荐供应商 | 系统根据历史采购推荐 3 家 |
| 供应商报价 | 待填写 |
| 交期 | 供应商反馈 |
| 选择建议 | 比价后建议 |

#### 3.11.3 流程
1. 系统自动生成询价单并推送至采购负责人；
2. 采购负责人确认供应商名单；
3. 系统发送询价邮件/飞书消息给供应商（可选）；
4. 供应商报价回填；
5. 系统自动比价，生成「采购建议书」；
6. 审批通过后生成采购订单。

## 7. 非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 图纸提交后 5 秒内完成校验；会议预约接口响应 < 3 秒；BOM 生成 < 10 秒 |
| 可用性 | 核心流程 99.5% 可用 |
| 安全 | 图纸文件加密存储；接口调用需 OAuth2/AKSK 认证；操作日志全记录 |
| 扩展性 | 支持后续接入其他会议系统、ERP、MES |
| 兼容性 | 支持主流浏览器及飞书/企业微信工作台 |

## 9. 风险与依赖

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 腾讯会议 API 权限不足 | 无法自动预约 | 提前申请企业版 API 权限 |
| ERP/MES 接口未就绪 | 库存/MES 数据无法拉取 | 先提供手动导入模板，后续接接口 |
| 图纸文件大，上传慢 | 体验差 | 支持分片上传、压缩包解析 |
| 评审专家时间冲突 | 会议无法按期召开 | 提供多个候选时段、支持人工调整 |
| 供应商报价回填不及时 | 采购延误 | 支持邮件/飞书催办、超时预警 |
