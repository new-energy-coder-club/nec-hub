## 🎯 部署概述

本指南将帮助您在生产环境中部署和配置图纸评审系统的基础联想功能。该功能基于 Cloudflare Workers 和飞书多维表格构建，提供高可用性和可扩展性。

### 部署架构
```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   用户浏览器     │───▶│  Cloudflare CDN  │───▶│  Cloudflare     │
│                 │    │                  │    │  Workers        │
│ - HTML/JS/CSS   │    │ - 静态资源缓存    │    │ - API 路由      │
│ - 移动端访问     │    │ - DDoS 防护      │    │ - 业务逻辑      │
└─────────────────┘    └──────────────────┘    └─────────────────┘
                                                        │
                                                        ▼
                                               ┌─────────────────┐
                                               │  飞书多维表格    │
                                               │                 │
                                               │ - 评审数据存储   │
                                               │ - 用户权限管理   │
                                               │ - 任务关联       │
                                               └─────────────────┘
```

## 🚀 快速部署

### 1. 环境准备

**系统要求**:
- Node.js 18.0.0 或更高版本
- npm 8.0.0 或更高版本
- Cloudflare 账户
- 飞书企业账户

**工具安装**:
```bash
# 安装 Node.js (推荐使用 nvm)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 18
nvm use 18

# 安装 Wrangler CLI
npm install -g wrangler

# 验证安装
node --version  # 应显示 v18.x.x
npm --version   # 应显示 8.x.x
wrangler --version
```

### 2. 项目部署

**步骤 1: 克隆项目**
```bash
# 克隆项目仓库
git clone https://github.com/new-energy-coder-club/nec-hub.git
cd nec-hub

# 切换到主分支
git checkout main

# 安装依赖
npm install
```

**步骤 2: 环境配置**
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量
nano .env
```

**步骤 3: 构建项目**
```bash
# 类型检查
npm run check

# 运行测试
npm run test

# 构建项目
npm run build
```

**步骤 4: 部署到 Cloudflare**
```bash
# 登录 Cloudflare
wrangler login

# 部署到生产环境
npm run deploy

# 验证部署
curl https://your-domain.com/api/health
```

## ⚙️ 环境配置

### 1. Cloudflare Workers 配置

**wrangler.toml 配置**:
```toml
name = "nec-hub"
main = "src/index.ts"
compatibility_date = "2024-01-01"

[vars]
ENVIRONMENT = "production"

[[kv_namespaces]]
binding = "REGISTRY"
id = "your-kv-namespace-id"
preview_id = "your-kv-preview-id"

[[r2_buckets]]
binding = "R2_BUCKET"
bucket_name = "your-r2-bucket"

[observability]
enabled = true
```

### 2. 环境变量配置

**必需的环境变量**:
```bash
# Cloudflare 配置
CLOUDFLARE_ACCOUNT_ID=your_account_id
CLOUDFLARE_API_TOKEN=your_api_token

# 飞书应用配置
FEISHU_APP_ID=cli_xxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx

# 应用配置
MCP_TOKEN=your_secure_mcp_token
REGISTRY_NAMESPACE=your_kv_namespace

# 数据库配置
DATABASE_URL=your_database_url
REDIS_URL=your_redis_url
```

**环境变量设置**:
```bash
# 使用 Wrangler 设置环境变量
wrangler secret put FEISHU_APP_ID
wrangler secret put FEISHU_APP_SECRET
wrangler secret put MCP_TOKEN

# 或使用 Cloudflare 控制台
# 访问 https://dash.cloudflare.com
# 进入 Workers > 您的应用 > 设置 > 变量
```

### 3. 飞书应用配置

**步骤 1: 创建飞书应用**
1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 创建企业自建应用
3. 获取 App ID 和 App Secret
4. 配置应用权限（需要 `bitable:read`, `bitable:write` 权限）

**步骤 2: 配置多维表格**
1. 创建飞书多维表格
2. 获取表格的 `app_token` 和各表的 `table_id`
3. 配置表格字段映射

**步骤 3: 配置回调地址**
```
回调地址: https://your-domain.com/auth/feishu/callback
权限范围: bitable:read, bitable:write, contact:read
```

  max: 100, // 每个IP最多100个请求
  message: "Too many requests from this IP"

**身份验证**:
```typescript
// JWT 验证
async function verifyAuth(request: Request): Promise<boolean> {
  const token = request.headers.get("Authorization")?.replace("Bearer ", "");
  if (!token) return false;
  
  try {
    const payload = await verifyJWT(token);
    return !!payload.userId;
  } catch {
    return false;
  }
}
```

### 3. 数据安全

**数据加密**:
```typescript
// 敏感数据加密
import { createCipheriv, createDecipheriv, randomBytes } from 'crypto';

const ENCRYPTION_KEY = process.env.ENCRYPTION_KEY; // 32字节密钥
const IV_LENGTH = 16;

function encrypt(text: string): string {
  const iv = randomBytes(IV_LENGTH);
  const cipher = createCipheriv('aes-256-cbc', Buffer.from(ENCRYPTION_KEY), iv);
  let encrypted = cipher.update(text);
  encrypted = Buffer.concat([encrypted, cipher.final()]);
  return iv.toString('hex') + ':' + encrypted.toString('hex');
}
```

## 🔄 备份与恢复

### 1. 数据备份

**自动备份**:
```bash
#!/bin/bash
# 每日数据备份脚本

DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="/backups/nec-hub_$DATE"

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份 KV 数据
wrangler kv:key list --namespace-id=$KV_NAMESPACE_ID > $BACKUP_DIR/kv_keys.json

# 备份配置
cp wrangler.toml $BACKUP_DIR/
cp .env $BACKUP_DIR/

# 压缩备份
tar -czf $BACKUP_DIR.tar.gz $BACKUP_DIR

# 清理旧备份（保留7天）
find /backups -name "nec-hub_*.tar.gz" -mtime +7 -delete
```

**手动备份**:
```bash
# 备份特定数据
wrangler kv:key get "user-prefs:user-123" --namespace-id=$KV_NAMESPACE_ID > backup_user_123.json

# 备份配置
wrangler kv:key get "drawing-review:config" --namespace-id=$KV_NAMESPACE_ID > backup_config.json
```

### 2. 灾难恢复

**恢复步骤**:
```bash
# 步骤 1: 恢复代码
git checkout main
git pull origin main

# 步骤 2: 恢复配置
cp backup/.env .env
cp backup/wrangler.toml .

# 步骤 3: 恢复数据
# 从备份恢复 KV 数据
wrangler kv:key put "user-prefs:user-123" --path=backup_user_123.json --namespace-id=$KV_NAMESPACE_ID

# 步骤 4: 重新部署
npm run deploy

# 步骤 5: 验证恢复
curl https://your-domain.com/api/health
```
