## 4. 优化建议（按优先级）

1. **补评审留痕规范（P0，零代码）**：评审会必须完整录制（≥实际议程时长）；会后 24h 内将妙记链接 + 结论写入对应流程事件表。本次已建立 events 表归档范式，可固化为 SOP。
2. **恢复 MCP 凭证（P0）**：`wrangler secret put FEISHU_APP_ID / FEISHU_APP_SECRET`，恢复 `query_bitable` 与审批链路。
3. **妙记接入评审流程（P1，功能开发）**：
   - `ReviewMinutes` 增加 `minuteToken`、`minuteUrl`、`transcriptRef` 字段；
   - 新增 `POST /api/drawing-review/:id/minutes:import`（入参 minute_token），服务端调妙记 API 拉 summary/todos/chapters 自动填充 `discussion`/`nextActions`；
   - 复用 `minutes-migration/build_docs.py` 的产物结构作为导入格式参考。
4. **补测试（P1）**：为 `saveMinutes` 与拟新增的 import 路径补 `src/drawing-review/__tests__/` 用例（含状态机限制：仅评审中/待评审可写）。
5. **配置治理（P1）**：配置 hardware-review 底表；核对 drawing-review 的 base 基线并更新 `drawing-review-config-summary.md`；推动附录 A 拍板与附录 B 后台配置执行（`approval_code` 归档）。
6. **底表 schema 强化（P2）**：events/comments 的「操作时间/评论时间」改日期类型、「操作人/评论人」改人员类型，存量文本可迁移。
7. **完成纪要迁移（P2）**：跑完 `build_docs.py` 生成 `minutes-migration/docs/`；两个 `.m4a` 用 `minutes +upload` 生成妙记补齐 AI 产物。
