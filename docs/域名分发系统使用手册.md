# NEC 域名分发系统使用手册

成员自助申请 `*.newenergycoder.club` 三级域名（也支持四级，见下文），绑定自己开发部署的应用。

- 入口页面：`https://hub.newenergycoder.club/apps/domains/`（仓库 `public/apps/domains/index.html`）
- 后端模块：`src/domains/`（路由挂在 `src/index.ts` 的 `/api/domains/*`；`wildcard.ts` 为泛域名应用直达）
- 管理后台：`https://hub.newenergycoder.club/apps/admin/`（仓库 `public/apps/admin/index.html`，后端 `src/admin/` 的 `/api/admin/*`）：DNS 记录查/增/删（含一键补泛解析 `*`）、边缘缓存清除、域名直达诊断；仅 队长/指导/管理员/维护者 可用；另有 `ADMIN_OPEN_IDS` secret（逗号/空格分隔的 open_id）作为超级管理员兜底，不依赖飞书名单表

## 零配置直达：R2 托管应用自动获得三级域名

Worker 已配置泛域名路由 `*.newenergycoder.club/*`（`wrangler.jsonc` routes + `src/domains/wildcard.ts`）。**用 MCP `deploy_app` 发布名为 `<name>` 的应用后，`https://<name>.newenergycoder.club` 即刻可访问**，无需在域名分发系统申请。

优先级（Host 命中泛域名时）：

1. `hub` / 保留子域名 → 走平台常规路由或透传回源（不劫持已有基础设施域名）
2. 域名分发系统登记过外部目标（CNAME 到 Vercel/Pages 等）→ 透传回源，具体 DNS 记录优先于泛解析
3. R2 存在 `apps/<name>/` → 直接托管（含边缘缓存）
4. 都没有 → 404 引导页

**一次性前提**：Cloudflare DNS 加一条 `*` 的代理记录（AAAA → `100::`，橙云）。Universal SSL 正好覆盖三级泛域名，证书零成本。注意 wrangler deploy 不会自动创建这条记录，需在控制台 DNS 页手动添加一次（或配置 CF_API_TOKEN 后用 API 创建）。四级域名不受泛域名证书覆盖，不在此服务范围。

## 成员使用

1. 先在门户（hub.newenergycoder.club）完成飞书登录。
2. 打开域名分发页面，填写：
   - **子域名**：小写字母/数字/中划线，2–63 字符；`hub`、`www`、`api`、`docs` 等保留名不可申请。
     - **四级域名**：子域名里带点即可，如填 `my-app.dev` 得到 `my-app.dev.newenergycoder.club`；最多 3 级标签。保留名规则：首标签按全量保留表校验；深级标签只拦 `hub`/`login`/`auth`/`admin`/`pay`/`sso` 等高危词。
   - **记录类型**：`CNAME`（推荐，指向托管平台主机名）或 `A` / `AAAA`（指向服务器 IP）。
   - **解析目标**：如 `my-app.pages.dev`、`cname.vercel-dns.com`、`<user>.github.io` 或 IPv4/IPv6。
   - **Cloudflare 代理（橙云）**：默认关闭。开启后由 Cloudflare 终止 TLS，自带 HTTPS；Vercel 等平台要求关闭（仅 DNS）。**四级及更深域名强制仅 DNS**（免费版 Universal SSL 只覆盖 `*.newenergycoder.club` 一级泛域名）。
3. 每个成员最多持有 **3** 个域名（vars `DOMAIN_MAX_PER_USER` 可调），不用了就「释放」。

### 四级域名的 HTTPS

| 层级 | 例子 | 证书来源 |
| --- | --- | --- |
| 三级 | `my-app.newenergycoder.club` | 开代理由 Cloudflare Universal SSL 覆盖；不开则由目标平台签发 |
| 四级及以下 | `my-app.dev.newenergycoder.club` | 只能仅 DNS，由目标平台（Vercel/Pages/Netlify 均支持任意深度自定义域名自动签 Let's Encrypt 证书）签发 |

若确实需要 Cloudflare 侧终止四级域名 TLS，需购买 Advanced Certificate Manager（约 $10/月），目前未启用。

### 常见平台绑定要点

| 平台 | 记录 | 平台侧操作 |
| --- | --- | --- |
| Cloudflare Pages | CNAME → `xxx.pages.dev` | Pages 项目 → Custom domains → 添加该三级域名 |
| Cloudflare Workers | CNAME → `xxx.workers.dev` | Worker → Settings → Domains & Routes → Custom Domain |
| Vercel | CNAME → `cname.vercel-dns.com`（不开代理） | Project → Settings → Domains → Add |
| GitHub Pages | CNAME → `<user>.github.io` | 仓库 Settings → Pages → Custom domain |
| 自建服务器 | A → 服务器公网 IP | 自行配置 Nginx/Caddy 证书 |

## 管理员配置

DNS 记录通过 Cloudflare API 落盘，需要两个 secret：

```bash
npx wrangler secret put CF_API_TOKEN   # API Token，权限：Zone → DNS → Edit（仅限 newenergycoder.club）
npx wrangler secret put CF_ZONE_ID     # 域名在 Cloudflare 控制台的 Zone ID
```

- **未配置凭证时系统仍可用**：申请保存为 `pending`，配置后成员在页面点「重试同步」即可补建 DNS 记录。
- 可选 vars（wrangler.jsonc）：`DOMAIN_ZONE`（默认 `newenergycoder.club`）、`DOMAIN_MAX_PER_USER`（默认 3）。
- 角色为 队长/指导/管理员 的成员不受限额约束，可释放任意成员的域名（`/api/domains/mine` 返回全量列表）。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/domains` | 公开目录（仅 active，脱敏，无 open_id） |
| GET | `/api/domains/mine` | 我的域名（登录；管理员返回全量） |
| POST | `/api/domains` | 申请 `{subdomain, type?, target, description?, proxied?}` |
| POST | `/api/domains/delete` | 释放 `{subdomain}`（本人或管理员） |
| POST | `/api/domains/retry` | 重试同步 pending/failed `{subdomain}` |

## 存储与实现说明

- 登记表：KV `domains:index`（列表，与 `apps:index` / `skills:index` 同一模式）。
- 条目字段：`subdomain / fqdn / type / target / proxied / description / owner / status / cfRecordId / createdAt / updatedAt`。
- `status`：`active`（已同步 Cloudflare）、`pending`（未配置凭证）、`failed`（同步失败，`error` 存原因）。
- Cloudflare 客户端在 `src/domains/cloudflare.ts`，删除时对 404/81044 幂等。
- HTTPS：Cloudflare Universal SSL 覆盖 `*.newenergycoder.club` 一级泛域名；不开代理时由目标平台签证书。
