## 提交方式（对应 MCP / 接口）

本项目尚无「报销提交」MCP 工具，R-01 报销走 **HTTP 接口**（MCP 侧 `submit_approval`/`add_records` 等可间接操作底层）：

1. **上传凭证**：`POST /api/approvals/upload`（multipart，单个 ≤10MB）→ 返回 R2 key `receipts/YYYYMMDD/...`
2. **整单提交**：`POST /api/erp/reimburse/submit`，JSON 体：

```json
{"lines":[{"cat":"工具耗材","item":"...","date":"2026-10-14","invno":"20位发票号","amount":"31.87","note":"销售方"}],"note":"","noinv":"","payee":{"method":"","account_name":"","account_no":"","bank":""},"attachments":["receipts/..."]}
```

- 约束：明细 ≤50 行；附件 ≤10 个；发票号 8/20 位；日期须在本赛季且 ≤ 今日；无附件时必须填 `noinv` 无票说明。
- 鉴权：需登录态 Cookie `nec_session`（门户飞书登录后取）；提交后进审批引擎（reimburse 流）+ D1 快照。
- MCP 工具侧映射：`submit_approval`（审批引擎底表提交，等效走流程）/ `query_bitable`+`add_records`（直写飞书财务表，绕审批）/ `send_notice`（审批通道通知）/ `list_todos`（查回执）。
