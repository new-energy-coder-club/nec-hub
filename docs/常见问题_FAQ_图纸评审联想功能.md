## 🔍 功能使用问题

### Q1: 联想功能什么时候触发？
**A**: 联想功能在以下条件满足时触发：
- 输入字符数 ≥ 2 个
- 输入框获得焦点
- 网络连接正常
- 用户已登录系统

**触发延迟**: 300ms 防抖延迟，避免频繁请求

---

### Q2: 联想结果不准确怎么办？
**A**: 联想结果不准确的可能原因和解决方案：

**原因 1**: 历史数据不足
- **解决方案**: 继续使用系统，系统会学习您的习惯
- **预期效果**: 使用 1-2 周后联想准确率显著提升

**原因 2**: 输入关键词过于模糊
- **解决方案**: 使用更具体的关键词
- **示例**: 输入 "PRJ-001" 而不是 "PRJ"

**原因 3**: 数据质量问题
- **解决方案**: 联系管理员检查历史数据
- **建议**: 定期清理和标准化数据

---

### Q3: 如何使用键盘导航联想列表？
**A**: 完整的键盘操作指南：

| 按键 | 功能 | 说明 |
|------|------|------|
| ↑ | 向上选择 | 在联想列表中向上移动 |
| ↓ | 向下选择 | 在联想列表中向下移动 |
| Enter | 确认选择 | 选择当前高亮的联想项 |
| Esc | 关闭列表 | 关闭联想建议列表 |
| Tab | 切换字段 | 在表单字段间切换 |

**提示**: 联想列表支持鼠标和键盘混合操作

---

### Q4: 一键加载默认值功能如何使用？
**A**: 使用步骤和注意事项：

**使用步骤**:
1. 点击表单右上角的「🔄 加载默认值」按钮
2. 系统自动填充项目编号、机型名称、版本号等
3. 根据需要修改默认值
4. 完成表单提交

**注意事项**:
- 默认值基于您的历史填写记录
- 首次使用时可能没有默认值
- 可以随时手动修改默认值
- 系统会持续学习您的偏好

---

### Q5: 基于任务的联想功能如何使用？
**A**: 功能说明和使用方法：

**功能说明**:
- 当您查看或编辑已有评审单时
- 系统会根据当前任务推荐相关内容
- 包括相关机型、历史项目、版本建议

**使用方法**:
1. 在评审单列表中选择一个已有评审单
2. 点击「查看详情」或「编辑」
3. 系统会在侧边栏显示智能推荐
4. 点击推荐项快速填充表单

**推荐类型**:
- **相关机型**: 同一项目下的其他机型
- **历史项目**: 同一设计师的其他项目
- **版本建议**: 基于历史版本的推荐

## 🔧 技术故障问题

### Q6: 联想功能完全没有响应？
**A**: 系统性的排查步骤：

**步骤 1**: 检查网络连接
```bash
# 测试网络连接
ping your-domain.com
curl -I https://your-domain.com/api/health
```

**步骤 2**: 检查浏览器控制台
- 打开浏览器开发者工具 (F12)
- 查看 Console 标签是否有错误信息
- 查看 Network 标签是否有失败的请求

**步骤 3**: 检查系统状态
- 访问 `/api/health` 端点
- 确认返回状态为 "healthy"

**步骤 4**: 联系技术支持
- 提供详细的错误信息
- 说明问题发生的具体步骤
- 提供浏览器和操作系统信息

---

### Q7: 联想 API 返回错误？
**A**: 常见 API 错误和解决方案：

**错误 401**: 未授权
- **原因**: 用户未登录或登录过期
- **解决方案**: 重新登录系统

**错误 403**: 禁止访问
- **原因**: 用户权限不足
- **解决方案**: 联系管理员检查权限设置

**错误 404**: 接口不存在
- **原因**: API 端点配置错误
- **解决方案**: 检查 API 路径是否正确

**错误 500**: 服务器错误
- **原因**: 后端服务异常
- **解决方案**: 联系技术支持团队

---

### Q8: 前端页面显示异常？
**A**: 常见前端问题和解决方案：

**问题 1**: 联想列表不显示
- **检查**: CSS 样式是否正确加载
- **解决**: 清除浏览器缓存，刷新页面

**问题 2**: 样式错乱
- **检查**: 浏览器兼容性
- **解决**: 使用最新版本的 Chrome/Firefox/Safari

**问题 3**: 交互不流畅
- **检查**: 网络延迟
- **解决**: 检查网络连接，尝试使用有线网络

## 🔐 账户权限问题

### Q9: 为什么我没有联想功能权限？
**A**: 权限检查和解决方案：

**权限要求**:
- 需要有效的飞书账号
- 需要登录 NEC 团队 AI 中台
- 需要图纸评审模块的访问权限

**检查步骤**:
1. 确认已登录系统
2. 检查用户角色和权限
3. 联系管理员确认权限配置

**解决方案**:
- 联系系统管理员开通权限
- 确认账户信息正确
- 检查是否有访问限制

---

### Q10: 用户偏好数据安全吗？
**A**: 数据安全和隐私保护：

**安全措施**:
- 所有数据都存储在您的个人账户中
- 数据传输使用 HTTPS 加密
- 敏感信息经过加密处理
- 不会泄露给第三方

**隐私保护**:
- 系统只学习您的填写习惯
- 不会收集敏感个人信息
- 您可以随时清除学习数据
- 支持匿名使用模式

## ⚡ 性能优化问题

### Q11: 联想功能响应慢怎么办？
**A**: 性能优化建议：

**客户端优化**:
- 使用有线网络连接
- 关闭不必要的浏览器标签
- 清理浏览器缓存
- 使用最新版本浏览器

**网络优化**:
- 检查网络带宽
- 避免高峰期使用
- 使用 CDN 加速

**系统优化**:
- 联系管理员检查系统负载
- 优化数据库查询
- 启用缓存机制

---

## 📱 移动端问题

### Q13: 移动端联想功能不工作？
**A**: 移动端特定问题排查：

**检查项目**:
- 确认使用支持的浏览器 (Chrome/Safari)
- 检查网络连接稳定性
- 确认屏幕触摸功能正常
- 检查浏览器版本是否过旧

**解决方案**:
- 更新浏览器到最新版本
- 清除浏览器缓存和 Cookie
- 尝试使用桌面模式
- 联系技术支持

---

### Q14: 移动端界面显示异常？
**A**: 移动端界面优化：

**常见问题**:
- 联想列表显示不全
- 按钮点击不灵敏
- 文字显示过小
- 布局错乱

**解决方案**:
- 使用横屏模式
- 调整屏幕缩放比例
- 清除浏览器缓存
- 尝试不同的浏览器

### Q15: 联想数据不同步？
**A**: 数据同步问题排查：

**可能原因**:
- 网络连接不稳定
- 服务器负载过高
- 数据缓存问题
- 权限配置错误

**解决方案**:
1. 刷新页面重新加载
2. 检查网络连接
3. 清除浏览器缓存
4. 联系技术支持

### Q16: 如何清除学习数据？
**A**: 数据清除方法：

**清除步骤**:
1. 联系系统管理员
2. 提供用户身份信息
