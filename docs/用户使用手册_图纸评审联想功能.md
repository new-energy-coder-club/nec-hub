## 💡 核心功能详解

### 🔍 智能联想功能

#### 项目编号联想
**触发方式**: 在项目编号输入框中输入前 2 个字符

**操作步骤**:
1. 点击「项目编号」输入框
2. 输入项目编号的前几个字符（如 "PRJ"）
3. 系统自动显示匹配的项目编号列表
4. 使用 ↑↓ 键或鼠标点击选择目标项目

**示例**:
```
输入: "PRJ"
联想结果:
  1. 项目: PRJ-001
  2. 项目: PRJ-002  
  3. 项目: PRJ-003
```

#### 机型名称联想
**触发方式**: 在机型名称输入框中输入前 2 个字符

**操作步骤**:
1. 点击「机型名称」输入框
2. 输入机型名称的前几个字符（如 "R1"）
3. 系统自动显示匹配的机型名称列表
4. 选择合适的机型

**示例**:
```
输入: "R1"
联想结果:
  1. 机型: R1底盘
  2. 机型: R1机械臂
  3. 机型: R1传送带
```

#### 上下文感知联想
**智能特性**: 系统会根据当前表单内容自动调整联想结果

**示例**:
- 当您选择项目编号 "PRJ-001" 后，机型名称联想会优先显示该项目下的相关机型
- 当您输入机型名称 "R1底盘" 后，系统会推荐相关的历史项目和版本信息

### 🔄 一键加载默认值

**功能说明**: 系统自动学习您的填写习惯，提供个性化的默认值

**操作步骤**:
1. 点击表单右上角的「🔄 加载默认值」按钮
2. 系统自动填充以下信息:
   - 📝 最近使用的项目编号
   - 📝 最近使用的机型名称
   - 📝 推荐的图纸版本号
   - 📝 当前登录用户作为设计负责人
   - 📝 结构化设计说明模板

**默认值内容**:
```
项目编号: PRJ-001 (最近使用)
机型名称: R1底盘 (最近使用)
图纸版本: V1.1 (基于历史版本推荐)
设计负责人: 张三 (当前登录用户)
设计说明: 【设计说明模板】...
```

### 🎯 基于任务的智能推荐

**适用场景**: 当您查看或编辑已有评审单时

**功能说明**: 系统会根据当前评审单的内容，推荐相关的项目和机型

**推荐类型**:
- **相关机型**: 同一项目下的其他机型版本
- **历史项目**: 同一设计师的其他项目
- **版本建议**: 基于历史版本的推荐版本号

**示例**:
```
当前评审单: DR-20261014-001 (项目: PRJ-001, 机型: R1底盘)

推荐结果:
  相关机型:
    1. R2底盘 (V1.1)
    2. R3底盘 (V2.0)
  
  历史项目:
    1. PRJ-002 (R4底盘)
    2. PRJ-003 (机械臂)
```

## ⚠️ 注意事项

### 输入要求
- **最少字符**: 输入至少 2 个字符才能触发联想
- **字符类型**: 支持中英文、数字、常见符号
- **大小写**: 不区分大小写

### 网络要求
- **稳定连接**: 联想功能需要稳定的网络连接
- **响应时间**: 正常情况下联想响应时间 < 100ms
- **离线使用**: 网络异常时会自动降级为基础输入

### 数据隐私
- **用户数据**: 所有联想数据仅存储在您的个人账户中
- **学习算法**: 系统只学习您的填写习惯，不会泄露敏感信息
- **数据安全**: 所有数据传输都经过加密处理

## 🔧 故障排除

### 常见问题

#### Q: 联想功能没有响应？
**A**: 请检查以下几点:
1. 确保网络连接正常
2. 确认输入字符数 ≥ 2 个
3. 尝试刷新页面重新登录
4. 清除浏览器缓存后重试

#### Q: 联想结果不准确？
**A**: 可能的原因:
1. 历史数据较少，系统还在学习阶段
2. 输入的关键词过于模糊
3. 当前项目是新项目，没有历史数据

#### Q: 默认值加载失败？
**A**: 请尝试:
1. 检查网络连接
2. 确认已登录系统
3. 联系系统管理员检查权限设置

#### Q: 移动端显示异常？
**A**: 建议:
1. 使用最新版本的浏览器
2. 尝试横屏模式
3. 清除浏览器缓存
4. 联系技术支持
