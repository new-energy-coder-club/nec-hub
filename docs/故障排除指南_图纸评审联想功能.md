## 🔴 紧急问题处理

### 系统完全不可用

#### 症状
- 所有 API 端点返回 5xx 错误
- 前端页面无法加载
- 健康检查失败

#### 诊断步骤
```bash
# 1. 检查服务状态
curl -I https://your-domain.com/api/health

# 2. 检查 Cloudflare Workers 状态
wrangler tail --format pretty

# 3. 检查 DNS 解析
nslookup your-domain.com

# 4. 检查 SSL 证书
openssl s_client -connect your-domain.com:443 -servername your-domain.com
```

#### 解决方案
```bash
# 方案 1: 重新部署
npm run deploy

# 方案 2: 回滚到稳定版本
git checkout v1.0.0
npm run deploy

# 方案 3: 检查环境变量
wrangler secret list

# 方案 4: 联系 Cloudflare 支持
# 访问 https://dash.cloudflare.com/support
```

### 数据库连接失败

#### 症状
- API 返回数据库连接错误
- 联想功能无法获取数据
- 用户偏好无法保存

#### 诊断步骤
```bash
# 1. 检查 KV 存储状态
wrangler kv:key list --namespace-id=$KV_NAMESPACE_ID

# 2. 检查网络连接
ping your-kv-namespace.your-account.workers.dev

# 3. 验证权限设置
wrangler kv:key get "test" --namespace-id=$KV_NAMESPACE_ID
```

#### 解决方案
```bash
# 方案 1: 检查 KV 命名空间配置
# 确认 wrangler.toml 中的 namespace-id 正确

# 方案 2: 重新创建 KV 命名空间
wrangler kv:namespace create "REGISTRY"
# 更新 wrangler.toml 中的 id

# 方案 3: 检查账户权限
# 确认 API Token 有 KV 读写权限
```

### 2. 监控脚本

**健康检查脚本**:
```bash
#!/bin/bash
# 系统健康检查脚本

HEALTH_URL="https://your-domain.com/api/health"
LOG_FILE="/var/log/health-check.log"

# 执行健康检查
response=$(curl -s -o /dev/null -w "%{http_code}" $HEALTH_URL)
timestamp=$(date '+%Y-%m-%d %H:%M:%S')

if [ $response -eq 200 ]; then
  echo "$timestamp - ✅ 系统正常" >> $LOG_FILE
else
  echo "$timestamp - ❌ 系统异常 (HTTP $response)" >> $LOG_FILE
  # 发送告警
  echo "系统异常告警" | mail -s "NEC Hub 系统异常" admin@newenergycoder.club
fi
```

**性能监控脚本**:
```bash
#!/bin/bash
# 性能监控脚本

API_URL="https://your-domain.com/api/drawing-review/suggestions?q=test"
LOG_FILE="/var/log/performance.log"

# 测量响应时间
start_time=$(date +%s%N)
response=$(curl -s -o /dev/null -w "%{http_code}" $API_URL)
end_time=$(date +%s%N)

response_time=$(( (end_time - start_time) / 1000000 ))
timestamp=$(date '+%Y-%m-%d %H:%M:%S')

echo "$timestamp - 响应时间: ${response_time}ms, 状态码: $response" >> $LOG_FILE

# 检查是否超过阈值
if [ $response_time -gt 1000 ]; then
  echo "$timestamp - ⚠️ 响应时间过长: ${response_time}ms" >> $LOG_FILE
fi
```

```typescript
// 数据清洗工具
class DataCleaner {
  static cleanProjectId(projectId: string): string {
    return projectId.trim().toUpperCase().replace(/[^A-Z0-9-]/g, '');
  }
  
  static cleanMachineName(machineName: string): string {
    return machineName.trim().replace(/\s+/g, ' ');
  }
  
  static normalizeData(data: any[]): any[] {
    return data.map(record => ({
      ...record,
      projectId: this.cleanProjectId(record.projectId),
      machineName: this.cleanMachineName(record.machineName)
    }));
  }
}
```

### 3. 备份策略

**自动备份**:
```bash
#!/bin/bash
# 每日自动备份脚本

BACKUP_DIR="/backups/$(date +%Y%m%d)"
RETENTION_DAYS=7

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份 KV 数据
wrangler kv:key list --namespace-id=$KV_NAMESPACE_ID > $BACKUP_DIR/kv_keys.json

# 备份配置文件
cp wrangler.toml $BACKUP_DIR/
cp .env $BACKUP_DIR/

# 备份代码
git bundle create $BACKUP_DIR/code.bundle --all

# 压缩备份
tar -czf $BACKUP_DIR.tar.gz $BACKUP_DIR

# 清理旧备份
find /backups -name "*.tar.gz" -mtime +$RETENTION_DAYS -delete

echo "备份完成: $BACKUP_DIR.tar.gz"
```
