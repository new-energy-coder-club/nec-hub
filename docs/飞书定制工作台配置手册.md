# NEC 飞书定制工作台配置手册

> 参考：万涂幻象《祥瑞的上下文》（2026-10-11）——飞书定制工作台从 0 到 1
> 我们的情况：nec-hub 已上线（https://hub.newenergycoder.club），MES 已挂工作台应用
> 本文目标：把全队飞书工作台按统一设计配置出来

---

## 0. 先做路径决策（对照原文"四条路径"）

| 路径 | 说明 | 适合我们吗 |
|---|---|---|
| ① 自带小组件自助搭建 | 布局 + 官方小组件拼，零代码，体验近原生 | 部分适合：公告、任务、文档入口可拼 |
| ② 自研小组件 | 有设计研发资源时自己做小组件 | 后期可选 |
| ③ 服务商定制 | 付费，不适合学生团队 | ❌ |
| ④ **网页嵌入** | 把整个工作台指向自有网页 | ✅ **我们已有 nec-hub，走这条**（卡兹克同款） |

**结论：路径 ④ 为主（嵌入 hub），路径 ① 为兜底**（如果免费版没有自定义工作台能力，就退回"推荐应用 + 小组件拼"的方案，见文末 Plan B）。

## 1. 权限配置（原文第一关，必须先做）

定制工作台是分级权限管，**先解决"谁能编辑"**：

1. 超级管理员登录 https://feishu.cn/admin
2. **企业设置 → 管理员权限 → 管理员角色 → 创建角色**
3. 勾选 **「定制工作台」** 权限
4. ⚠️ 关键开关：勾选 **「允许向下级管理员角色分配权限」**——之后队长/组长才能继续往下授权
5. 把战队负责人加进这个角色

> 原文提示：已有权限的管理员可以继续给下级分部管理员建子角色分权。对应我们：队长有权限后，可以给各组组长分配。

## 2. 动手前想清楚两件事（原文清单，已按 NEC 填好）

| 问题 | 我们的答案 |
|---|---|
| 谁来拍板 | 队长 + 各组组长 |
| 做给谁用 | 全员；按组别（机械/电控/视觉/运营）差异化可选 |
| 解决什么问题 | 队员进飞书一键直达：仓库 MES、任务进度、应用广场、Skill 中心 |
| 长什么样 | 直接用 nec-hub 现有门户（已含四 Tab），不用重新设计 |
| 有什么资源 | 有研发（自己）、零预算 → 路径 ④ |
| 效果怎么评估 | 上线两周后发飞书问卷问队员（原文建议，别靠感觉） |

## 3. 配置步骤（网页嵌入路线）

### Step 1 · 创建工作台
- 管理后台 → 工作台 → 定制工作台 → **新建工作台**
- 命名：`NEC 战队工作台`

### Step 2 · 选嵌入方式
- 在编辑器中选择 **「网页嵌入 / 自定义网页」** 组件（或直接将工作台入口配置为网页）
- 填入：`https://hub.newenergycoder.club`
- ⚠️ 原文提示的代价：网页嵌入性能不如小程序流畅——我们的 hub 是纯静态页 + Worker API，首屏 < 10KB，影响很小

### Step 3 · 发布与启用
- 编辑器右上角 **发布** → 设置启用范围：**全部成员**（或按赛季分组）
- 设为**默认工作台**：全员打开飞书"工作台"即见中台

### Step 4 · 验证
- 桌面端 + 手机端各开一个普通队员账号确认
- 重点测：MES 免登（上一步 PR 合并后）在嵌入 WebView 里是否正常跳转

## 4. Plan B（免费版无"自定义工作台"入口时）

按原文路径 ① 拼一个原生工作台：

| 区域 | 用什么小组件 |
|---|---|
| 顶部 | 公告（赛季里程碑、例会通知） |
| 应用区 | 添加已上架的「NEC 仓库作业台」+「常用应用」固定 |
| 数据区 | 多维表格仪表盘（任务进度表直接挂） |
| 文档区 | 常用文档快捷入口（培训材料、技术方案库） |

体验损失可接受，且和 nec-hub 网页版互补（浏览器照常访问 hub）。

## 5. 与 nec-hub 的协同关系

```
飞书定制工作台（入口层）
   ├── 路径④：整页嵌入 hub.newenergycoder.club  ← 主推
   └── 路径①：原生小组件 + MES 应用图标        ← 兜底
nec-hub（能力层）：应用广场 / Skill 中心 / MCP 部署 / 免登后端
飞书多维表格（数据层）：名单 / 任务 / 物资 / 财务
```

数据在飞书、能力在 hub、入口在工作台——和原文架构一致。

## 6. 风险与备注

- **版本限制待确认**：原文未明确定制工作台的版本要求，免费版可能无「自定义工作台」入口 → 配置时如果找不到入口，直接走 Plan B
- **嵌入网页的免登**：WebView 内跳转 OAuth 需重定向 URL 白名单已配（`https://mes.newenergycoder.club/home.html`），hub 如接 OAuth 同理要加 `https://hub.newenergycoder.club`
- **切换前广播**：启用默认工作台前在战队群通知，避免队员找不到原工作台功能
