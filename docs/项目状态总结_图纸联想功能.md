     ↓              ↓                ↓
  联想端点      联想逻辑处理      数据查询

## 📖 使用指南

### 对于用户
1. **开始填写**: 点击"提交评审单"按钮
2. **智能联想**: 在项目编号或机型名称输入框中输入前几个字符
3. **选择建议**: 使用键盘或鼠标选择合适的联想项
4. **快速提交**: 点击"加载默认值"自动填充表单
5. **完成提交**: 确认信息无误后提交

### 对于开发者
1. **API 调用**: 使用 `/api/drawing-review/suggestions` 获取联想建议
2. **集成前端**: 参考 `public/index.html` 中的联想实现
3. **扩展功能**: 基于 `SuggestionService` 类扩展新的联想类型
4. **测试验证**: 运行 `npm run test` 验证功能正确性
