KV 元素 KEY VISUAL

「为黎明而造」的视觉语言：工程蓝图 × 破晓地平线。所有队员作品（网页 / PPT / 海报）统一使用以下元素。

蓝图网格

粗 92px / 细 23px，青色 5%-13% 透明度，仅铺在 Hero 或封面区。

破晓地平线

页面底部 3px 实线 + 渐变淡出，象征黎明；青 → 浅青 → 透明。

破晓太阳

双圆环（实线 + 虚线）加十字准星，置于页面右上或地平线中央。

编号芯片

01找物品

等宽字体编号 + 藏青描边，用于步骤、清单、模块标注。

PPT 标准模板 POWERPOINT

内置 7 种版式：封面 / 目录 / 章节过渡 / 内容·要点 / 内容·图文 / 数据表格 / 结尾页。
用法：下载后另存为你的文件 → 复制对应版式页 → 替换文字与图片。
字号规范：封面标题 54 · 页标题 28 · 正文 13 · 注释 10-12；标题微软雅黑 Bold，数字与编号用 Consolas。
注意：不要更换配色、不要拉伸 Logo、不要在标志上加阴影/描边。

使用禁忌 DON'T

不要拉伸变形等比缩放，不要单独拉宽或压扁。
不要改配色不要给标志换色、加渐变映射或彩虹色。
不要加效果禁止投影、描边、发光、斜切、旋转 3D。
不要换字体队名组合中的字体不可替换为宋体/楷体等。
不要置于杂乱背景背景看不清时换反白版或加纯色底。
不要重排组合横版组合的比例与间距不可自行调整。
