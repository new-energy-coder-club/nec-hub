# 数据看板配置手册 — 飞书多维表格接入

> 目标：门户「数据看板」Tab 实时渲染 **队员名单 / 任务进度 / 物资台账 / 财务报销**。
> 前提：已按 `docs/飞书免登接入_MES.md` 创建企业自建应用，并在 Worker 配置 `FEISHU_APP_ID` / `FEISHU_APP_SECRET`（两者与免登复用同一应用）。

---

## 第一步 · 飞书开放平台开通多维表格权限

1. 打开 https://open.feishu.cn/app → 进入应用详情 → **「权限管理」**
2. 添加权限：**`bitable:app:readonly`**（查看多维表格）
3. **「版本管理与发布」→ 创建版本并发布**（权限变更必须发版才生效；企业自建应用一般免审核）

## 第二步 · 把应用加为多维表格协作者

- 打开目标多维表格 → 右上角「分享」→ 添加协作者 → 搜索应用名（如 `NEC 仓库作业台`）→ 给 **「可阅读」**
- ⚠️ 不做这步，读表会报 `Forbidden`（飞书错误码 1254033 等）

## 第三步 · 拿 app_token 与各表 table_id

- 表格 URL 形如：`https://xxx.feishu.cn/base/<app_token>?table=<table_id>&view=vewxxx`
  - `app_token` = `/base/` 后的一段（复制时**不要**带 `?` 之后的内容）
  - 每切一张表，URL 的 `table=` 参数变化，即为该表 `table_id`（`tbl` 开头）
- 建议四张表建在同一份多维表格里（base 相同）：队员名单 / 任务进度 / 物资台账 / 财务报销

## 第四步 · 写入中台配置（Agent 原生）

把下面 Prompt 发给已接入 nec-hub MCP 的 Agent（未配置时，门户「数据看板」Tab 有同款 Prompt 可复制）：

```
请帮我配置 NEC 中台的数据看板（飞书多维表格）：
1. 打开飞书多维表格，从浏览器地址栏复制 app_token 与各表的 table_id：
   URL 形如 https://xxx.feishu.cn/base/<app_token>?table=<table_id>&view=...
2. 调用 nec-hub MCP 的 config_dashboard（action=set），传入 base 与 tables（tasks / inventory / members / finance → table_id）
3. 配置完成后打开门户「数据看板」Tab 确认数据渲染
```

或手动直接调 MCP：`config_dashboard action=set base=<app_token> tables={"tasks":"tbl...","inventory":"tbl...","members":"tbl...","finance":"tbl..."}`

- 四张表可只配一部分，未配置的表在看板中显示「未配置 table_id」
- 写入后自动清缓存并立即拉取；重复执行 = 覆盖更新

## 第五步 · 验证

1. 门户 https://hub.newenergycoder.club → 「数据看板」Tab 应出现统计卡片与任务/物资/报销区块
2. 命令行：`curl -s https://hub.newenergycoder.club/api/dashboard | python -m json.tool`
3. 试读单表：MCP `query_bitable table=tasks`（可加 `filter=底盘` 做包含过滤）

## 机制说明

| 项 | 行为 |
|---|---|
| 缓存 | 每张表 KV 缓存 5 分钟；飞书接口故障时自动降级展示缓存快照（页面标注「缓存快照」） |
| 字段识别 | 字段名模糊匹配（状态/负责人/截止/数量/金额/组别等常见命名），表格列名无需严格一致 |
| 财务脱敏 | 未登录 → 隐藏；已登录队员 → 仅汇总；角色含 **队长/财务/指导** → 可见明细（见 PRD FE-01） |
| 报销识别 | 门户提交报销时上传发票图片/PDF，浏览器本地 OCR（Tesseract.js + pdf.js，不上传第三方）自动填写金额/报销时间/发票号；财务表若含「发票号」文本列则写入该列，否则追加到事项文本 |
| 角色判定 | 读「队员名单」表的 `权限角色` 列，按 open_id（其次姓名）匹配当前登录人；角色缓存 60 秒，改表后 1 分钟内生效 |

## 常见问题

| 问题 | 处理 |
|---|---|
| 获取 tenant_access_token 失败 | 检查 `FEISHU_APP_ID` / `FEISHU_APP_SECRET` secret；确认应用已发版 |
| 读表报 Forbidden / 1254033 | 应用未加为表格协作者（第二步），或未开通 `bitable:app:readonly` 权限（第一步） |
| 读表正常但写入报 Forbidden | 多维表格链接分享是「组织内可阅读」，应用只能读不能写。改为「组织内可编辑」：Base → 分享 → 链接分享范围 → 组织内可编辑；或 CLI `lark-cli drive permission.public patch --token <base> --type bitable --data '{"link_share_entity":"tenant_editable"}' --as user --yes` |
| 写关联/纪要/事件表报「cell value does not match」或静默无记录 | 文本字段不接受数组值，代码里写 `关联评审单: reviewId`（字符串），不要写 `[reviewId]` |
| 某表显示「未配置 table_id」 | `config_dashboard` 的 tables 里漏了这张表，补上即可 |
| 改了队员角色不生效 | 角色缓存 60 秒，稍等；或确认名单表里有该用户的 open_id / 姓名 |
