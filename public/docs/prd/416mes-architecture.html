流程说明

1操作员扫 LOC:CTN:ITM（或 LOC:ITM），提交 receive / issue 作业
2扫码台生成带稳定 opId 与期望版本的受控命令，进入写入管道
3管道 POST /api/feishu/item-operation 至 Vercel Serverless
4服务端读飞书真源，生成 before/after 计划，审计账落 PREPARED
5apply 写 items 状态机（pending→in_stock→out），append itemOperations（APPLIED，opId 去重）
6回读飞书校验，账本置终态
7终态回执返回前端；结果未知时查原 opId 终态，禁止换号重发
8ack 后更新 IndexedDB 本地镜像（records / 草稿 / 日志）
9离线时写入 outbox，恢复在线后按原 opId 重试
10在线时经 /state、/incremental 增量拉取 + 三方合并；/reconcile 只读对账，schema 失配 fail-closed
11标签短链 /i·/c 扫码直达云端查询页；每笔操作留操作人 / 设备 / 时间，可 complete-valid 重放校验
已冻结 / 移除的历史方向：InvenTree（localhost:8001，已从产品范围移除）· 闲鱼同步（G3 冻结，仅保留脚本）· MAT 数量账（v3.13 起封存为只读历史视图）
